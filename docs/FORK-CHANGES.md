# Изменения форка

- **Сворачиваемые панели боковой колонки.** «Сессии» и «Отображение» свёрнуты по умолчанию, «Контекст» раскрыт. Нажатие заголовка переключает состояние панели; высота пересчитывается при сворачивании и изменении размера терминала. `extensions/sidebar/default-panels.ts`, `extensions/sidebar/index.ts`, `extensions/sidebar/registry.ts`.
- **Иерархия сессий.** Каталог читает `parentSession` из JSONL и связывает дочерние сессии с родителями по пути. В быстром списке дочерние сессии скрыты, ограничение в пять строк снято, список можно прокручивать. В менеджере дочерние сессии сгруппированы под родителями, группы раскрываются; поиск учитывает потомков. `extensions/session/catalog.ts`, `extensions/session/manager.ts`, `extensions/session/panel.ts`, `extensions/index.ts`.
- **Удаление сессий в корзину Windows.** На Windows вместо внешней команды `trash` используется PowerShell и системная корзина; на других платформах остаётся `trash`. Ошибки читаются из stderr или stdout, постоянное удаление не выполняется. `extensions/session/mutations.ts`.
- **Полное скрытие собственных инструментов в режиме Hidden.** Для принадлежащих расширению строк инструментов `render()` возвращает пустой список, обработка кликов отключена. Выполнение инструментов и учёт вызовов не меняются; чужие инструменты не затронуты. `extensions/tool-view/compact-spacing.ts`.
- **Компактный «Контекст».** Открыт при старте: строка `модель · Thinking · процент`, полоса заполнения, `in / out / cache` и свёрнутый `Composition`. В раскрытом составе — английские `System`, `Tools`, `Messages`, `Tool Results`, `Summary`, `Other`, `Images`. Процент и полоса показывают заполнение окна модели; `in / out / cache` — накопленные за активную ветку данные провайдера, восстановленные из сообщений и дополненные по завершении ответов. При нехватке ширины строка токенов переносится. Прежние подробные показатели TTFT/TPS и дельты из панели убраны. `extensions/ctx/panel.ts`, `extensions/ctx/tokens.ts`, `extensions/index.ts`.
- **Ресурсы и режимы в «Отображении».** Правила, Навыки, Плагины и MCP удалены из «Сессий» и размещены четырьмя кликабельными строками внизу «Отображения» под статистикой вызовов. Режимы `Normal`, `Compact`, `Hidden` также показываются по одному на строку: каждый режим полностью виден и имеет собственную область нажатия, даже когда боковая панель узкая. При старте «Сессии» и «Отображение» свёрнуты. `extensions/session/panel.ts`, `extensions/tool-view/panel.ts`, `extensions/tool-view/controller.ts`, `extensions/sidebar/default-panels.ts`.
- **Сброс блокировки переключения сессии.** При `session_start` сбрасывается `switchRequested`, чтобы после успешного перехода можно было переключиться снова. `extensions/index.ts`.
- **Русский интерфейс.** Переведены названия панелей, действия, уведомления и сообщения диалогов и MCP; названия режимов Tool View оставлены на английском, остальные действия и уведомления — на русском. Связанные тесты обновлены под новые строки. `extensions/index.ts`, `extensions/ctx/`, `extensions/dialogs/`, `extensions/mcp/`, `extensions/session/`, `extensions/sidebar/`, `extensions/tool-view/`.
